# Phase Plan & Result Records

本目录用于存放 L3 开发每个 phase 的：

1. 讨论确认后的计划文件
2. 实施完成后的结果文件

建议命名：

- `phase-a-plan.md`
- `phase-a-result.md`
- `phase-b-plan.md`
- `phase-b-result.md`
- `phase-result-template.md`

执行约束：

- 先有 `*-plan.md`，经确认后再进入实现。
- 实现完成后补 `*-result.md`，记录改动、验证、遗留 blocker。

结果文件（`*-result.md`）必须至少包含：

## D. 最终输出

- [ ] 回显本轮目标达成情况
- [ ] 回显边界遵守情况
- [ ] 回显 blocker 与下一步
- [ ] 回显本轮新增/变更的 `RFX-*` 清单

## E. 测试情况

- [ ] 本轮测试设计/测试执行范围
- [ ] 实际执行命令
- [ ] 结果（通过/失败/未执行）与原因
- [ ] 风险与后续测试建议
