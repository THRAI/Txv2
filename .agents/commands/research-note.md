# Research Note

Use when external docs, repos, papers, or codebase investigation affect a
txKernel decision.

1. Read `docs/progress/templates/research.md`.
2. Create `docs/progress/research/YYYY-MM-DD-short-title.md`.
3. Record the question, findings, applicability, and sources.
4. Separate observed facts from inferences.
5. Link any follow-up decision record if the research changes direction.
