# Update Status

Use after meaningful progress, a blocker, a completed plan, or as the status
part of the finish catch-up workflow.

1. Read `docs/progress/STATUS.md`.
2. Keep it short: current shape, open blockers, latest decisions.
3. Link to the newest decision, plan, handoff, or research note when useful.
4. For a completed task, include changed surface, verification, next step, and
   blockers, or point to the progress record that contains those details.
5. Do not put long analysis in `STATUS.md`; create a durable record instead.
