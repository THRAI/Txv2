# Record Decision

Use when a choice should survive the chat.

1. Read `docs/progress/templates/decision.md`.
2. Create `docs/progress/decisions/YYYY-MM-DD-short-title.md`.
3. State the decision, context, consequences, and alternatives.
4. If the decision changes architecture semantics, name the `docs/design/...`
   file that must be updated.
5. Update `docs/progress/STATUS.md` if the decision changes current direction.
